# Timebox

每天排一组任务块，只有顺序和预估时长，没有固定时钟时间。计划在电脑上的 Google Sheet 里排，
手机上打开页面一件件做、标完成情况，没做完的填原因。数据存在 Google Sheet，Mac 和手机共用一份。

## 一、先搭 Google 这一端

1. 新建一个 Google Sheet（名字随意，不用手动建表头）
2. 扩展程序 → Apps Script，删掉默认内容，粘贴 `Code.gs` 全文
3. 把第 4 行的 `CHANGE_ME` 改成你自己的口令（只在 Apps Script 编辑器里改，别改仓库里的文件）
4. 编辑器顶部的函数下拉选 `setup` → 运行 → 按提示授权。表格里会多出「任务」和「每日时长」两页，表头和「分类」下拉都建好了（以后更新了 `Code.gs`，再运行一次 `setup`：会刷新分类下拉，老表会自动补上缺的「任务描述」「实际时长（分钟）」列）
5. 右上角 部署 → 新建部署 → 类型选「网页应用」
   - 执行身份：**我**
   - 谁有权访问：**任何人**
6. 复制生成的 `…/exec` 网址

「任何人」是必须的：浏览器发过去的是匿名请求，带不上你的 Google 登录态。
口令就是替代品——对不上的请求会被 `doPost` 直接挡掉。

> 每次改完 `Code.gs`，要重新「部署 → 管理部署 → 编辑 → 版本选新建」才生效，
> 否则跑的还是旧代码。这是最常见的坑。

## 二、再搭网页这一端

把这个文件夹推到 GitHub 仓库，Settings → Pages → Source 选 main 分支根目录。
一两分钟后 `https://<用户名>.github.io/<仓库名>/` 就能打开。

代码是公开的，**但数据不在代码里**——数据全在你的 Sheet，别人打开这个网址
只会看到一个空白应用。唯一要注意的是别把口令写进仓库里的任何文件（它只存在
你浏览器的 localStorage 里）。

想连代码也不公开，就用 Cloudflare Pages 连私有仓库，步骤一样。

## 三、装到手机

Safari 打开网址 → 分享 → 添加到主屏幕。第一次打开后点右上角 Settings，
填 Apps Script 网址和口令。Mac 上也填一次，两边就对上了。

## 四、每天怎么用

电脑上在表格的「任务」页排计划，一件事一行；手机上打开或刷新页面，就能看到当天的任务。

| 列 | 怎么填 | 手机上 |
|---|---|---|
| 日期 | `2026-09-14`。同一天的几行用复制粘贴（拖右下角会逐行 +1） | 按日期显示 |
| 任务内容 | 必填 | 显示 |
| 任务描述 | 长段说明，可不填 | 点任务名展开，手机上也能补充 |
| 预计完成时间（分钟） | 数字，不填按 30 | 显示 |
| 实际时长（分钟） | 可不填；手机上标 Done / Partial 后，在任务名右边填 | 填了的话「min done」按实际算 |
| 拟定顺序 | 数字，小的先做，可以同号。**当天最大的那个数 = 可选**（当天只有一种数字时不算） | 按它排序；可选的淡紫底 + Optional 标记 |
| 分类 | 下拉：主线 / 工作 / 娱乐 / 琐事 | 左侧色条和顶部色块：主线绿、工作蓝、娱乐橙、琐事棕（没填是灰色） |
| 审核 | 这个任务的存在有没有加成，可不填 | 不显示 |
| 是否完成 | 手机标完自动写：`ok`、`Partial｜原因`、`Later｜原因`、`Drop｜原因`，原因在手机上自己填。也可以手填，中文 部分 / 顺延 / 放弃 也认，写别的文字算 Partial 的原因 | 显示成状态 |
| 实际次序（自动） | 手机自动记第几件做完，不用管 | 不显示 |

- 列可以挪位置、中间也能插自己的列，只要表头文字不改
- 手机上按住左边的分钟数上下拖，调整顺序。拖过的那天以这台设备上的顺序为准；没拖过的按「拟定顺序」排
- 手机上新加的任务没有拟定顺序，排在最后
- 每天可用的时长填在「每日时长」页：`日期 | 可用时长（分钟）`，一天一行；没填的日子用页面 Settings 里的默认值

## 同步是怎么工作的

- 任何改动后 **3 秒**自动写一次（合并连续操作，不然点四下发四次请求）
- 页面被切走或关掉时用 `sendBeacon` 补发一次
- 打开页面或切换日期时从表里读回，**以表为准**
- 但如果本地有还没传上去的改动（断网时改的），则以本地为准，先推上去
- 手机只回写「是否完成」「实际次序」，以及在手机上改过的「任务描述」「实际时长」，写在原来那行；日期、任务、时长、顺序、分类、审核手机不会改。
  手机上新加的任务追加到表的末尾；手机上不能删任务，要删去表里删整行
- 行靠「日期 + 任务内容」对上，所以**手机已经打开过的任务别在表里改名**，否则会被当成两件不同的任务

单人使用这套「最后写入者赢」够用了。要避免的唯一场景是：Mac 上改完立刻
断网关页面，然后手机上改同一天——这时两边都认为自己是对的。

## 积累之后看什么

一两个月后，值得看的是：「预计完成时间」求和的日均值（一天到底装得下多少）、「是否完成」里原因的分布
（是估时的问题还是被打断的问题）、按「分类」看完成率，以及「审核」里没加成的任务占了多少时间。
